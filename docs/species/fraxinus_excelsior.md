# Fraxinus excelsior (frêne commun) — fiche de traits

Jeu de référence : `data/validation/fraxinus_excelsior.ron` (41 entrées).

## Port et architecture
- Grand arbre à houppier ovoïde ouvert, branches ascendantes, feuilles composées opposées de 20-35 cm ; bourgeons terminaux noirs et gros, branchaison opposée (fourchage fréquent après gel ou broutage, Atlas). Modèle architectural : non vérifié.
- Héliophile à l'âge adulte, juvéniles tolérants à l'ombre.

## Particularités à modéliser
- **Chalarose** (*Hymenoscyphus fraxineus*) : mortalité >90 % dans plusieurs pays (Atlas) ; mort du jeune arbre dans la même saison ; sensibilité clonale liée à une sénescence foliaire précoce (WP fr). Le moteur n'a pas de pathogène de couronne de ce type : à signaler.
- Agrile (*Agrilus planipennis*) : absent d'Europe de l'Ouest ; hors périmètre.
- Cœur noir (coloration non fongique) après 70-80 ans.
